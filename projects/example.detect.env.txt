# The detector's opt-in (bin/detect.sh, card #36): no model, one metric, a rolling
# baseline, fixed bands. Sourced after projects/<name>.env, so it already has
# PROJECT_REPO, BOARD_OWNER and BOARD_NUMBER. Copy this to projects/<name>.detect.env
# (dropping the .txt; see projects/README.md) to turn detection on for a project —
# merging that file is what does it: deploy/install.sh enables
# watcher-detect@<name>.timer for every projects/<name>.detect.env it finds, and reruns
# on every deploy. Leave it unmerged (or named with the .txt) for a project with nothing
# worth watching this way.

# required. Plain words for what the metric is — goes straight into the card a breach
# files, so write it the way you'd want to read it there.
DETECT_WHAT="example metric"

# required. A command, run from the project's own checkout (60s timeout), that prints
# exactly one number — higher is worse. riffmap's own is a single health probe script;
# yours can be anything that exits with a number on stdout.
DETECT_METRIC_CMD="echo 0"

# optional. A live page named in the filed card as the artifact to look at. Leave unset
# if there is no one page that shows the problem.
DETECT_LOOK_URL=

# optional. How many past readings the rolling average is taken over. Default: 20.
DETECT_BASELINE_WINDOW=20

# optional. Readings needed before a breach can be tiered at all — guards against
# judging a brand-new metric off one or two points. Default: 3.
DETECT_MIN_READINGS=3

# required. The rolling average at or above this: log a line, nothing else.
DETECT_SMALL_BAND=1

# required. The rolling average at or above this: file a Backlog card (and, while that
# card stays open, file no second one for the same breach).
DETECT_LARGE_BAND=2
