# The triage lane's shape, as a second systemd instance of the same project
# (projects/riffmap-triage.env is the real one). It sources the project file and sets
# exactly PROJECT_NAME, LANE_AGENTS, LANE_COMMAND and LANE_WORKDIR — nothing else: every
# other knob (the board, the repo, Discord, the quota caps) comes from the file it
# sources. Copy this to projects/<name>-triage.env (dropping the .txt; see
# projects/README.md) once projects/<name>.env exists, and fix the sourced filename.
. "$(dirname "${BASH_SOURCE[0]}")/example.env"
PROJECT_NAME=example-triage

# Takes exactly the cards with no `agent:` label — "-" is the sentinel for that, and it
# is named exactly once across a project's lane files so no card can belong to two lanes
# at once. If <name>.env's own LANE_AGENTS is unset (the single-lane default), add
# "!<build-lane's-agents>,-" to it before running a triage lane beside it, or the two
# will fight over the same cards.
LANE_AGENTS="-"
LANE_COMMAND=/triage
LANE_WORKDIR=root
